# UXUY 幸运大抽奖 · 单浏览器活动

此 index.html 已内联图片、样式、程序和二维码库。开奖需联网读取真实 BNB Chain 主网 RPC，无需钱包。

库存和开奖记录保存在当前浏览器 IndexedDB，开奖确认时原子扣减库存，重复请求保留同一结果。整个活动请使用同一台电脑、同一浏览器和同一网址。清除网站数据、更换浏览器或网址会得到独立的库存。

本次新活动使用独立规则版本与数据库，旧版开奖记录保留。普通页面隐藏服装数量与概率，球拍共10份，每份一双，展示剩余份数。

同浏览器可查验记录，跨设备可查看 BscScan 交易链接。GitHub Pages 从 main 分支 / (root) 发布。
